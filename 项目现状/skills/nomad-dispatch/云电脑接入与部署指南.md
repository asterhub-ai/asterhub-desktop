# 移动云电脑（远程 Windows 主机）接入 Nomad 集群与部署指南

本文档专为在**移动云电脑 / 远程 Windows 主机**上运行的 Agent 或自动化脚本编写。执行完本文档各步骤后，该主机将作为计算节点（`cloud-pc`）接入位于家庭局域网内的 Nomad 分布式算力集群。

---

## 架构说明与前置状态

- **调度大脑 (Nomad Server)**：`192.168.1.199:4646`（位于家里 24 小时开机的 Ubuntu 网关上）。
- **网络打通方式**：通过已建立的 WireGuard 隧道连接，网关内部已完成对 `192.168.1.0/24` 的双向 NAT 转发。
- **前置依赖**：本机上的 WireGuard 客户端已经成功激活连接（可正常 `ping 192.168.1.199`）。

---

## 自动化执行步骤（请在管理员 PowerShell 中执行）

### 第一步：确认网络连通性与识别隧道网卡

```powershell
# 1. 验证到 199 大脑的连通性
$pingTest = Test-Connection -ComputerName 192.168.1.199 -Count 2 -Quiet
if (-not $pingTest) {
    Write-Error "无法连通 192.168.1.199，请先确保 WireGuard 隧道处于已激活(Active)状态！"
    exit 1
}
Write-Host "WireGuard 隧道连通正常。" -ForegroundColor Green

# 2. 自动定位到达 192.168.1.199 的网卡别名
$tunnelAlias = (Find-NetRoute -RemoteIPAddress 192.168.1.199 |
    Where-Object { $_.InterfaceAlias } |
    Select-Object -Last 1).InterfaceAlias

Write-Host "检测到 WireGuard 接口名称为: $tunnelAlias" -ForegroundColor Cyan
```

---

### 第二步：下载并安装 Nomad 2.0.7

```powershell
$ErrorActionPreference = 'Stop'

# 创建工作与数据目录
New-Item -ItemType Directory -Force -Path "C:\nomad", "C:\nomad\data", "C:\nomad\logs" | Out-Null

# 下载官方 Nomad 2.0.7 Windows x64 二进制
$nomadZip = "C:\nomad\nomad.zip"
if (-not (Test-Path "C:\nomad\nomad.exe")) {
    Write-Host "正在下载 Nomad 2.0.7..." -ForegroundColor Cyan
    Invoke-WebRequest -Uri 'https://releases.hashicorp.com/nomad/2.0.7/nomad_2.0.7_windows_amd64.zip' `
                      -OutFile $nomadZip `
                      -UseBasicParsing

    Expand-Archive -Path $nomadZip -DestinationPath "C:\nomad" -Force
    Remove-Item $nomadZip -Force -ErrorAction SilentlyContinue
}

Write-Host "Nomad 二进制就绪: C:\nomad\nomad.exe" -ForegroundColor Green
```

---

### 第三步：写入节点配置文件

```powershell
$hclContent = @"
datacenter = "dc1"
data_dir   = "C:/nomad/data"
bind_addr  = "0.0.0.0"
log_file   = "C:/nomad/logs/nomad.log"

name = "cloud-pc"

client {
  enabled           = true
  node_class        = "cloud"
  servers           = ["192.168.1.199:4647"]
  network_interface = "$tunnelAlias"
}

plugin "raw_exec" {
  config {
    enabled = true
  }
}
"@

# 使用无 BOM 的 UTF-8 编码写入
[IO.File]::WriteAllText("C:\nomad\nomad.hcl", $hclContent, [Text.UTF8Encoding]::new($false))
Write-Host "配置文件已写入 C:\nomad\nomad.hcl" -ForegroundColor Green
```

---

### 第四步：注册并启动 Windows 自启服务

```powershell
# 停止现有服务并清理旧数据目录，以保证新名称顺利注册
if (Get-Service -Name nomad-client -ErrorAction SilentlyContinue) {
    Stop-Service nomad-client -ErrorAction SilentlyContinue
    Start-Sleep 2
} else {
    New-Service -Name nomad-client `
                -DisplayName 'HashiCorp Nomad Client' `
                -BinaryPathName '"C:\nomad\nomad.exe" agent -config="C:\nomad\nomad.hcl"' `
                -StartupType Automatic | Out-Null
}

# 清理旧的节点注册标识
Remove-Item C:\nomad\data\* -Recurse -Force -ErrorAction SilentlyContinue

Set-Service -Name nomad-client -StartupType Automatic
Start-Service nomad-client
Start-Sleep 5

$status = (Get-Service nomad-client).Status
Write-Host "Nomad Client 服务状态: $status" -ForegroundColor Green
```

---

### 第五步：验证节点是否成功加入集群

在移动云电脑本地验证集群全局节点：

```powershell
$env:NOMAD_ADDR = "http://192.168.1.199:4646"
& "C:\nomad\nomad.exe" node status
```

输出中看到 `cloud-pc` 状态为 `ready` 即表明重命名与挂载完成。
