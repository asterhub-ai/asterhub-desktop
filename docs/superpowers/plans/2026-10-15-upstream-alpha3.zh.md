# AsterHub alpha.3 跟进任务清单

[English](2026-10-15-upstream-alpha3.md) | 中文

## 目标

选择性吸收 DSH `0.2.1-alpha.3` 的桌面可靠性修复与实用功能，保留 AsterHub 账号、Sub2API 路由、签名精选插件和独立桌面产品版本。

## 任务

- [x] 收拢已验证的 alpha.2 分支与 master，保留支付方式中文名称。
- [x] Windows 更新对话框销毁前释放模态状态。
- [x] 修复会话恢复与存储提供方卸载；限制会话列表读取并发。
- [x] 精选插件安装后刷新代码，并在需要时提示重启。
- [x] 接入有界终端双向输入，保留进程退出前的最后输出。
- [x] 修复会话行顺序、滚动和工作过程收起行为。
- [x] 适配 pi-ai 1.1.0，转换时保留原始协议历史。
- [ ] 遮挡用户消息中可识别的凭据，提供显式显示控件。
- [ ] 添加同时调整正文、代码和终端字号的桌面快捷键。
- [ ] 接入渐进式 Office 指引，同步随包资源及冒烟检查。
- [ ] 运行定向回归、会话快照、类型检查、构建、依赖、lint 和文档检查。
- [ ] 每组实施后执行本地审查并解决确认的问题。
- [ ] 构建并验证 Windows 未签名测试安装器，将 macOS 检查列为待验收。

## 约束

不引入 CLI 产品模式、Worktrees、远程共享、独立模型提供方目录或已取消的助手团队功能。不发布产物、不修改产品版本、不增加旧版迁移行为、不上传签名凭据。实际录音仍由用户自行测试。

## 验证记录

每项任务完成后在此记录实施和验证结果。缺少环境或凭据时标记未验证，不能记为通过。

- 基线与 Windows 对话框：16 项定向测试通过，跳过一项平台用例。本地 Codex 审查未发现可操作缺陷；审查器单独尝试测试时遇到 Corepack 缓存权限错误。上述定向测试已在审查沙箱外完成。
- 会话可靠性：定向测试覆盖预设复用、工作区关联、共享列表并发和提供方卸载。首次并行运行有五项 JSONL Worker 用例超时，设定 30 秒测试期限后全部通过。真实 Loader 卸载测试和 Windows 持久化卸载回放通过；原有 PowerShell 回放通过，POSIX 回放和 macOS 尚未验证。Host 与会话控制器类型检查通过。审查发现工作区关联竞态，修复前的负对照失败，修复后两个相关测试文件通过。自动复查因 Codex 使用额度耗尽中断，仍待完成。
- 插件刷新：文件比较与 profile 重新组合会重载有变化的插件，包括签名精选插件更新。设置界面已提供本地化重启原因。定向包测试和界面测试通过；Windows 拒绝创建文件符号链接时，两项相关用例明确跳过。Host、Client 类型检查及范围内的类型感知 lint 通过。Codex 审查未发现可操作回归；审查器尝试测试时遇到 Corepack 沙箱权限错误，记录中的本地测试已单独完成。
- 会话组在额度恢复后已完成复查，未发现可操作缺陷。审查器尝试测试时遇到 Corepack 沙箱权限错误；实际验证依据仍为上述单独完成的定向测试与回放。
- 终端双向流：10 个定向测试文件通过（265 项测试，一项平台跳过）。Host 构建、终端 Client 类型检查、范围内类型感知 lint 及 522 项文档类型等价检查通过。Codex 审查未发现可操作问题，审查沙箱无法运行测试。输入同时受原始 UTF-8 字节和编码帧大小限制，已完成的输出流保留最终内容。桌面交互留待最终安装器验收。
- 会话布局：Client 类型检查与范围内 lint 通过。包级回归的失败项已修复并重跑，最终布局检查通过 280 项测试。审查发现问题回复缺少输入位置、选择器未覆盖 flow 包装层，两项均已修复；回复负对照在修复前失败，修复后 87 项相关测试通过。最终 Codex 复查未发现可操作缺陷。真实浏览器几何和安装器交互仍待验收。
- pi-ai：固定为 1.1.0，保留参数增量解析补丁；协议转换保留原始历史，九项跨协议往返测试通过。修复夹具和品牌断言后，适配器、目录、参数流、序列化、运行时补丁与 Windows PTY 测试通过。包级类型检查、范围内 lint 和新增 PowerShell 空文本历史回放通过，POSIX 回放尚未验证。桌面准备脚本会复制并校验选定的 pi-ai 与 node-pty 补丁。审查要求补写 Azure 旧版升级指南，但本任务明确只做开发中的当前版本、不写此类指南，因此更新当前配置说明。最终安装包运行时和真实 Sub2API 验收仍待完成。
