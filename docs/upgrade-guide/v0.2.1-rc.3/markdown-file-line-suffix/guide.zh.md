# Markdown 文件链接中的数字后缀

[English](guide.md) | 中文

## 变更

以 `:24` 或 `:24-30` 结尾的本地 Markdown 目标现在会打开后缀之前的文件并定位到第 24 行。此前，后缀属于文件名。链接到名称确实以冒号加数字结尾的文件时需要转义。带有 `#L24` 片段的目标保持原有解释方式。

## 迁移

1. 链接到 `notes:24` 这样的文件名时，将字面冒号编码：`[notes](./notes%3A24)`。引用行号时，使用 `[notes:24](./notes:24)` 或 `[notes:24](./notes#L24)`。
2. 在已完成的消息中点击链接，确认预览打开预期的文件名和行号。
